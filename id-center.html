기능 상태 안내

현재 Hub의 Google 로그인·프로필 꾸미기·개인화 홈 동기화는 기존 기능을 이용합니다. 아래 공개 설정은 이 기기의 설계 초안으로만 저장됩니다. 친구·공식 기록·게임 초대·자리 예약·서버 동기화는 아직 실제로 작동하지 않습니다.

👤 프로필과 계정

계정 닉네임과 고유 ID

계정 닉네임을 기본으로 사용하고 게임별 기본 이름과 방별 표시 이름을 따로 설정하는 구조. 공개 고유 ID는 중복 없이 관리하며 내부 인증 UID와 분리합니다.

게임별 별명·고유 ID 생성: 설계 단계

게스트와 정식 계정

게스트도 아이콘·기록·업적·즐겨찾기·설정을 사용할 수 있고, 친구 추가 및 여러 기기 간 안전한 복구는 정식 계정에서 지원하도록 설계합니다.

기존 프로필 편집은 내 프로필에서 가능

통합 기록과 업적

게임별 승패·점수·최고 기록을 종류별로 표시. 서버 검증된 업적과 오프라인 임시 달성을 구별하고, 경기 ID를 이용해 중복 합산을 막습니다.

서버 연동 미구현

즐겨찾기·최근 사용·공통 설정

Hub의 고정 카드·추천·최근 방문 기록 기능은 계속 활용하고, 전체 즐겨찾기와 테마·사운드 등 공통 설정은 단계적으로 확장합니다.

Hub 개인화 홈 일부 구현

🔒 공개 범위 설계 초안

아래 선택은 현재 브라우저에만 저장되며 다른 사람의 서버 접근 권한을 변경하지 않습니다. 실제 공개 권한은 Firebase 보안 규칙과 함께 구현해야 합니다.

👥 친구와 초대

친구 검색과 관계

공개 ID 검색, 친구 신청·수락·거절·취소, 친구 삭제, 차단 및 신고. 게스트는 친구 기능을 사용할 수 없도록 계획합니다.

친구 프로필 방문

닉네임과 아이콘은 공개할 수 있지만, 게임 기록·업적·온라인 상태·친구 목록은 각자의 공개 설정에 따릅니다.

🎮 초대 정책 미리보기

실제 방 생성·알림 발송은 하지 않는 정책 미리보기입니다.

  • 친구에게 초대를 보내면 온라인·오프라인 모두 알림 센터에서 확인합니다.
  • 초대 시간은 서버가 확정한 발송 시각부터 계산합니다.
  • 자리 보호를 켜면 최대 2분간 정원 내 예약석을 유지합니다.
  • 수락 시 친구·차단·방 상태·정원을 서버에서 재검증합니다.
  • 실제 입장에 성공한 뒤에만 참가 완료로 표시합니다.
  • 대기실에서 예약 설정을 변경하되, 기존 유효 예약을 보호하는 방식을 추천합니다.

🔔 알림 센터 정책

알림 종류

게임 초대, 친구 신청, 초대 수락·거절·만료, 업적. 알림의 읽음 상태와 수락·참가 상태는 별개입니다.

방해 금지와 만료

팝업이나 푸시는 끌 수 있어도 알림 기록은 유지. 초대는 기본 10분이며 5·10·15·30분 중 선택합니다. 만료된 초대는 참가할 수 없습니다.

☁️ 게스트 저장·계정 연결·동기화

로컬 + Firebase 혼합형

기기 설정·오프라인 임시 진행·동기화 대기열은 로컬에, 계정과 검증된 경쟁 기록·친구 관계는 Firebase에 저장하는 방향입니다.

안전한 계정 연결

게스트 → 신규 계정은 익명 인증 연결, 기존 계정 로그인은 중복 제거·병합 미리보기·확정 저장을 별도로 처리. 검증 전 게스트 데이터를 삭제하지 않습니다.

오프라인 상태 구분

인터넷 연결과 Firebase 인증·Database 읽기/쓰기·동기화 성공 여부를 별개 상태로 표시할 계획입니다.

서버 보안

공개/비공개 데이터를 분리하고 실제 참가·업적·친구 관계는 신뢰할 수 있는 서버 로직과 Firebase Rules로 검증해야 합니다.
