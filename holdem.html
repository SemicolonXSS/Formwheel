  3. 공용 카드와 내 카드 중 가장 강한 5장 조합으로 승부합니다.
  4. 족보 (강한 순): 로열 플러시(스트레이트 플러시의 최고 형태) → 스트레이트 플러시 → 포카드 → 풀하우스 → 플러시 → 스트레이트 → 트리플 → 투페어 → 원페어 → 하이카드.
  5. 같은 족보라면 구성 숫자와 킥커를 비교합니다. A는 보통 가장 높으며 A-2-3-4-5 스트레이트에서는 1로 취급합니다.
