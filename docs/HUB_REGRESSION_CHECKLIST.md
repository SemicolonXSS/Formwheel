# Formwheel Hub 빠른 회귀 점검표

Hub UI/UX를 수정한 뒤 배포 전에 확인할 항목입니다. **실제 테스트가 완료되기 전에는 통과로 표시하지 마세요.**

## 기본 탐색
- [ ] PC와 모바일에서 홈 화면이 정상 표시된다.
- [ ] 카드 보기와 간편 보기 전환이 정상 작동하고 새로고침 후 선택이 유지된다.
- [ ] 검색어 입력, 검색어 지우기, 필터 및 정렬을 각각 확인한다.
- [ ] 프로젝트 카드의 링크가 올바른 페이지로 이동한다.
- [ ] 키보드만으로 주요 탐색 요소에 접근할 수 있고 포커스가 보인다.

## 개인화와 데이터 보존
- [ ] 즐겨찾기, 고정, 추천 제외를 변경한 뒤 새로고침해도 상태가 유지된다.
- [ ] 로그인 상태와 비로그인 상태에서 각각 기본 화면을 확인한다.
- [ ] 기존 사용자 설정을 초기화하거나 덮어쓰지 않는다.
- [ ] Firebase 권한 오류가 발생해도 Hub의 공개 프로젝트 탐색이 막히지 않는다.
- [ ] 데이터 구조 또는 Rules 변경 시 별도 백업·마이그레이션·권한 검증을 수행한다.

## 화면 및 오류
- [ ] 좁은 모바일 화면에서 가로 스크롤이나 겹치는 버튼이 없다.
- [ ] 다크/라이트 테마에서 텍스트와 버튼이 읽기 쉽다.
- [ ] 이미지나 네트워크 요청 실패 시에도 카드와 안내 문구가 표시된다.
- [ ] 브라우저 콘솔에 새 JavaScript 오류가 없다.

## 배포 확인
- [ ] 변경 파일과 diff를 검토했다.
- [ ] 가능한 자동 테스트를 실행하고 결과를 기록했다.
- [ ] GitHub Pages 배포 후 실제 URL에서 주요 기능을 다시 확인했다.

> 이 문서는 테스트 **절차**이며, 항목의 통과나 배포 성공을 보증하지 않습니다.
