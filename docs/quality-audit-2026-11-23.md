## 수정 내용

- 홈 카드의 분류·인원·연결·난이도·NEW 문구, 보조 설명과 푸터의 대비를 높였습니다.
- 스도쿠에 9개 행과 81개 칸의 올바른 소유 관계, 선택/고정 상태와 단일 Tab 진입점을 제공합니다. 칸 재생성 후 클릭·방향키 포커스를 복원하며, 저장된 값과 메모의 새로고침 복원도 확인했습니다.
- 캘린더 날짜 버튼의 실제 표시 문구를 접근 가능한 이름에 포함하고, 다른 달 날짜의 낮은 대비를 수정했습니다.
- LOOP 리듬 버튼의 박자 설명과 예약 상태를 음성 이름에 포함했습니다. 홈 추천·Spotlight·EDU·Factor Lab 링크/버튼 이름도 표시 문구와 일치시켰습니다.
- 다른 페이지의 버튼·설명 대비, 이름을 허용하지 않는 그룹의 역할, 제목 단계와 본문·내비게이션·공유 영역을 수정했습니다.
- 본문 바로가기를 보완하고, Code의 존재하지 않는 파비콘 경로 및 아이콘 누락을 수정했습니다. 카탈로그의 Hub 경로를 사이트맵에 반영하고 문자열 형태의 역슬래시 n을 실제 XML 공백으로 수정했습니다.
- 기존 PIXEL WAR 검사 2개는 현재 데이터 규칙의 필드 구조에 맞췄습니다. 이 부분은 기존 PR #26의 검증된 소스 수정을 재사용했습니다. #26과 바로가기·아이콘·사이트맵 수정 범위가 일부 겹치지만 LOOP 오디오/서비스 워커 수정은 이 변경에 포함하지 않았습니다.

## 집계 방식과 재현

한 건은 `파일 + axe 규칙 + DOM 대상`입니다. 예를 들어 스도쿠의 행 누락은 게임판 1건과 부모 역할이 잘못된 칸 81건으로 검출됐지만, 하나의 구조 수정으로 함께 해결됩니다. 홈의 동일한 CSS 토큰이 여러 카드에서 실패한 경우도 각각의 위치가 기록됩니다. 검사 실패가 사라졌다고 해서 독립적인 기능 버그 수를 늘려 세지 않습니다. 아이콘·사이트맵·포커스·테스트 복구 등 별도 소스 수정은 이 axe 집계에 추가하지 않았습니다.

## 범위와 되돌리기

기본 테마·새 브라우저 컨텍스트의 공개 페이지 검사입니다. Firebase 외부 요청을 차단했으므로 로그인·서버 저장·에뮬레이터·운영 데이터 동작을 검증한 결과는 아닙니다. Rules·Firebase 경로·잔액·기존 저장 형식은 변경하지 않았습니다. 다른 프로젝트로 이동하는 리다이렉트 4개, meta-refresh 포워더, 보관본 및 격리 iframe이 있는 Secret 제작소의 전체 자동 검사는 집계에서 제외했습니다.

수정 브랜치의 커밋을 되돌리면 UI와 검사 변경을 함께 복원할 수 있습니다. DB 마이그레이션이나 운영 배포를 수행하지 않았습니다.
