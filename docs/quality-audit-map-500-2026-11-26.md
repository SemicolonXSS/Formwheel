**기존 에디터에는 canvas 1개가 있었다.** 504는 원래 DOM 요소 수가 아니라 실제로 내보낸 맵 모델의 논리적 타일 위치 수다. 임의로 캔버스 픽셀을 나눈 수나 만든 시험 데이터의 개수가 아니다. 캔버스는 초점을 받지 못했고, 편집 화면에서 키보드 입력으로 맵을 바꿀 수 없었다. 모서리를 마우스로 편집하면 실제 JSON 값이 바뀌는 반면 키보드 시도 뒤 맵은 그대로인 것을 확인했다. 같은 입력 경로 결함이 504개 위치 모두에 적용된다.

수정 후 504개 셀을 실제 방향키로 순회하면서 각각 Space로 배치하고 셀 값을 확인했다. 고유 시작점 A/B를 복원한 뒤 **제품의 실제 내보내기 JSON 전체를 예상 행렬과 대조**했다. 반복 화면·도구·입력 방식은 다시 세지 않았다. 이전 감사에 같은 앱·파일·검사 항목은 없다. 이 집계는 axe 자동 위반 수가 아닌 별도 조작·실행 검사다.

맵 모델과 내보내기 형식은 그대로 사용하고 화면을 네이티브 그리드로 표시한다. Tab 진입점 하나, 방향키·Home/End·Ctrl+Home/End, 좌표·지형 안내와 최소 28px 영역을 제공한다. 마우스 드래그는 한 번의 되돌리기로 묶이며 터치는 탭으로 배치하고 밀어서 판을 스크롤한다. 실제 터치 제스처 뒤 내보낸 맵이 변하지 않았는지도 확인했다. 저장·재열기와 시작점 하나만 유지하는 동작도 통과했다.
