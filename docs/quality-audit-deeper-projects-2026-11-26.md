# 프로젝트별 추가 수정 — 2026-11-26

**실제 결함 11개를 수정했고 폴리리듬·클릭커·PVP에서 각 300개, 총 900개 회귀 시나리오를 통과했다.** 요청한 ‘각 300곳 추가 수정’ 수량에는 미달한다. 900은 매개변수별 검증 수이며 수정 위치나 독립 결함 수가 아니다. 기존 보고서의 음악 큐·획득량 표시·격자 경계 수정은 이번 결함 수에 다시 넣지 않았다.

[클릭커 PR #4](https://github.com/SemicolonXSS/Formwheel_Clicker/pull/4) · [PVP PR #4](https://github.com/SemicolonXSS/Formwheel_PVP/pull/4)

폴리리듬은 0.08초 이내에 입력한 방향 전환이 타일 목록에는 거절되면서 내부 방향만 바뀌는 문제를 수정했다. 홀드 시작에 적용하던 판정 오프셋을 끝 판정에도 사용한다. 제작 버튼의 Enter 입력은 이제 버튼의 역할대로 동작하며 포인터는 누른 순간의 시점을 유지한다. 녹화는 오디오 재생 준비가 성공한 뒤에만 기존 노트를 교체하고, 닫기·취소·파일 변경·게임 시작 시 대기 중인 녹화도 취소한다. 오디오 선택 해제는 빈 `src` 대신 속성을 제거한다. 녹화 시작 실패·늦게 완료된 재생 요청·게임과 녹화 중첩은 하나의 녹화 수명 관리 결함으로 묶었다.

폴리리듬 매트릭스는 두 방향에서 1~75ms 간격으로 거절된 입력 150개와 내장 차트의 서로 다른 홀드 노트 150개에 +200ms 오프셋을 적용한 끝 판정이다. 수정 전 300개 모두 실패했고 수정 후 모두 통과했다. 이는 300개의 원인이나 편집 위치가 아니다. 별도 네이티브 키보드·포인터 입력, 녹화 오류 및 취소 검사 6개도 통과했다. 실제 기기의 음향 지연을 측정한 결과는 아니다.

클릭커는 자동 획득량을 표시된 유효 초당 획득량과 보이는 동안의 경과 시간으로 계산하고 1점 미만 잔량을 기존 version-2 저장 형식에 추가한 `autoRemainder`로 이어 간다. 숨김 전 보이는 시간과 강화 전의 시간을 먼저 정산하며 숨겨진 동안의 시간은 지급하지 않는다. 기존 업데이트당 2초 상한은 유지한다. 자동 지급은 잘못 잘리던 시간을 반영하도록 달라지며, 클릭 지급·강화 가격·기존 누적 기록은 바꾸지 않는다. 입력 확인 창에는 키보드 완료, 초점 진입·유지·복귀, 배경의 기존 inert 상태 복원 및 화면 축소 시 위치 보정을 추가했다. 신뢰할 수 없는 클릭 거절과 세션 순위 검토 정책은 유지한다.

클릭커 매트릭스는 기존 자동 강화 레벨 1·4·5·9·20, 격리된 누적 획득 지수 0·20·34·70·100, 12가지 1초 분할 시점의 조합이다. 같은 1초를 한 번에 처리한 결과와 나눠 처리한 결과를 비교했다. 원래 231/300개에서 누락이 있었고 수정 후 300개 모두 같았다. 69개는 원래부터 통과한 회귀 보호 사례다. 숨김·복귀, 저장·재열기, 강화 시점, 키보드 확인, 초점, Tab, 크기 변경 및 모달 axe 검사도 통과했다. 해당 조합 수를 버그 수로 세지 않았다.

PVP는 가로로 맵 밖 좌표를 걸을 수 있다고 판단해, 플레이어가 벽에 둘러싸인 열린 가장자리 맵에서 AI 탐색이 무한히 확장되는 문제를 막았다. 이동·탄환 경계는 모두 28×18 맵 안에 한정한다. Studio 맵은 A/B 시작점을 각각 하나만 허용한다. 저장한 목록 하나가 잘못된 형식이어도 나머지 정상 제작물을 불러오고, 저장된 맵을 열 때 이전 문서의 되돌리기 이력을 지운다.

PVP 매트릭스는 검사에서 만든 열린 가장자리·밀폐 플레이어 맵과 서로 다른 AI 시작 좌표 300개의 조합이다. 원본 탐색이 브라우저를 멈추지 않도록 **테스트 HTTP 응답에만** 1,024회 방문 제한과 내부 함수 접근을 넣었다. 원본은 300개 모두 이 제한을 넘었고 수정 후 각 탐색이 최대 504셀 안에서 끝났다. 운영 소스에는 테스트 접근이나 강제 방문 제한을 넣지 않았다. 경계·중복 시작점·목록 복구·다른 문서 열기와 되돌리기도 통과했다.

이전 450개 선정 사례, 폴리리듬 2,880노트, PVP 504개 네이티브 키보드 편집·내보내기, 포인터·터치·저장, 10개 배치의 axe 및 6개 AI 실행 검사가 모두 통과했다. 루트 스크립트 154개 블록/파일, 카탈로그 75개 프로젝트·사이트맵 40개 URL, 55개 페이지 탐색, Node 테스트 11개 파일과 클릭커 구문·로컬 참조 16개 및 리더보드 테스트도 통과했다. 직전 루트 PR #36 CI 전체가 성공한 것을 확인했다.
