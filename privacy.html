개인정보 및 데이터 이용 안내

업데이트: 2026-10-08

어떤 내용이 저장되나요?

온라인 기능은 사용자가 입력한 닉네임, 설문 응답, 게임 점수, 방 참가 상태, 채팅 및 AI 학습 내용을 Firebase에 저장할 수 있습니다. 로그인 앱은 Firebase Authentication을 사용합니다. Google 로그인은 해당 계정의 인증 프로필을 사용합니다.

새 Casino 로그인은 비밀번호를 Realtime Database에 저장하지 않습니다. 이전 계정 데이터의 삭제나 이전은 아직 수행하지 않았습니다.

내 기기에 남는 내용

초안, 자리 배치 결과, 게임 기록, 세션, 일부 파일은 localStorage 또는 IndexedDB에 저장됩니다. 브라우저 사이트 데이터 삭제 시 초기화됩니다. Music에서 직접 올린 오디오와 Tool의 이미지 변환은 현재 브라우저에서 처리합니다. 앱이 명시적으로 온라인 저장을 제공하는 경우 화면 설명을 확인하세요.

공유 및 접근 범위

공개 채팅, 공개 음악, 방 게임 데이터는 다른 이용자에게 보일 수 있습니다. 서버 접근 권한은 화면의 버튼 제한만으로 보호되지 않습니다. 운영 Rules와 서버 검증 상태는 Check에서 확인하세요. 민감한 개인정보를 공개 설문·채팅·게임에 입력하지 마세요.

삭제와 계정 관리

이 기기 기록은 브라우저 사이트 데이터 관리에서 삭제합니다. 서버 기록과 이전 계정 데이터는 프로젝트 관리자에게 삭제를 요청해야 합니다. 로그인 종료만으로 서버 기록이 삭제되지는 않습니다. 관리자 연락처와 서버 데이터 보관 기간은 아직 설정되지 않았습니다.

이 안내는 현재 구현의 데이터 동작을 설명합니다. 실제 서비스 운영 정책과 삭제 창구는 프로젝트 관리자가 확정해야 합니다.
