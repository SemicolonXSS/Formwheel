# Formwheel SYNC — v1.0

공식 주소(예정): https://semicolonxss.github.io/Formwheel/sync/

## 게임 방법
- 2~6명이 서로 말하지 않고 같은 질문의 답을 선택합니다.
- 6라운드 종료 시 누적 점수로 팀의 싱크력을 확인합니다.
- 라운드 기본 점수는 (가장 많이 선택한 답의 인원수 ÷ 전체 인원수) × 100 반올림입니다.
- 모두 같은 답을 선택하면 25점 보너스와 연속 성공 기록이 쌓입니다.

## 플레이 모드
- **한 기기 파티**: 인터넷 및 로그인이 필요 없습니다. 이름 2~6개를 입력하고 휴대폰을 넘겨 가며 답합니다.
- **온라인 방**: Firebase 로그인(기존 ID 또는 익명) 후 방을 생성하거나 6자리 코드로 참가합니다. 2~6인. 답은 공개 전까지 게임 화면에 표시되지 않습니다. 참가자가 제출하지 않는 경우 40초 후 방장이 결과를 공개할 수 있습니다.

## 배포 확인 사항
- 웹 페이지 및 허브 카드는 이 저장소의 GitHub Pages에서 제공됩니다.
- 온라인 방이 작동하려면 Firebase Realtime Database의 `database.rules.json`을 **실제 Firebase 프로젝트 formwheel에 배포**해야 합니다. GitHub 커밋만으로 보안 규칙이 적용되지는 않습니다.
- Firebase Auth에서 익명 로그인 사용 여부를 확인하세요. Anonymous 비활성화 시에는 정식 로그인 계정만 이용할 수 있습니다.
- 온라인 기능은 실제 브라우저 두 대에서 생성·참가·투표·퇴장·방 종료를 재검증해야 합니다.
- 테스트 전에는 실제 배포된 Rules를 백업하고, Firebase 콘솔 Rules Playground로 새 경로 `syncRooms`의 권한을 검증하세요.
- 방장 퇴장 시 방이 삭제되고, 일반 참가자 퇴장 시 참가자 자리만 해제됩니다.

## 데이터
온라인 방에는 임의 방 코드, 플레이어가 입력한 닉네임, Firebase UID, 선택지 번호, 게임 진행 상태가 저장됩니다. **실명·전화번호·주소를 닉네임에 쓰지 마세요.** 게임 진행용으로만 사용하세요.

## 파일
- `sync/index.html`: UI, 오프라인 파티, 온라인 Firebase 룸 로직
- `assets/app.js`: 허브의 SYNC 카드
- `database.rules.json`: 방/투표별 권한 규칙 (배포 별도)
- `sitemap.xml`: 신규 페이지 URL
